# 游戏按键自动化工具 - 需求文档

**版本**: v1.1
**日期**: 2026-05-20
**状态**: 已确认

## 1. 项目背景

在全屏游戏中，经常需要重复执行一系列机械操作（例如：定时点击防止离线、自动战斗循环、挂机采集等）。手动操作不仅繁琐，长时间重复也难以保持稳定。本项目旨在开发一个带有图形界面的桌面 EXE 工具，内置常用操作方案，同时支持用户自定义编排操作序列，一键启动自动执行，需要时一键停止。

## 2. 目标用户

- 游戏玩家，需要在全屏游戏中执行重复性操作
- 不要求用户具备编程知识 —— 通过图形界面即可选择和编排操作序列

## 3. 核心功能概览

| 编号 | 功能 | 描述 |
|------|------|------|
| F1 | 热键启停 | 按下指定热键开始自动操作，按下停止热键立即终止 |
| F2 | 预设方案库 | 内置 4 套常用操作方案，即选即用 |
| F3 | 自定义方案 | 通过 GUI 界面新建、编辑、删除自定义操作序列 |
| F4 | 方案管理 | 预设与自定义方案统一管理，可切换、可查看 |
| F5 | 游戏兼容 | 使用 DirectInput 方式发送按键，适配全屏/3D 游戏 |
| F6 | EXE 打包 | 打包为独立可执行文件，无需安装 Python 环境 |

## 4. 详细功能需求

### 4.1 操作序列

用户可以定义一组按顺序执行的操作，支持以下操作类型：

**键盘操作**：
- 操作类型：键盘按键（如 `space`、`f`、`1`、`enter` 等）
- 按下持续时间：模拟真实按下时长（如 0.1 秒），可配置

**鼠标操作**：
- 操作类型：鼠标左键点击、鼠标右键点击
- 按下持续时间：可配置

**等待操作**：
- 固定等待：指定秒数（如等待 100 秒）
- 随机等待：指定最小和最大秒数范围，每次随机取值（模拟人类操作间隔）

**循环控制**：
- 整个操作序列支持无限循环执行，直到用户按停止键（可配置是否循环）

### 4.2 内置预设方案

软件内置 4 套预设方案，**只读不可修改**：

| 编号 | 名称 | 用途 | 典型操作 |
|------|------|------|----------|
| P1 | 挂机防离线 | 防止长时间不操作被踢下线 | 定时点击 + 空格等按键 |
| P2 | 自动战斗循环 | 连续按键释放技能 | 技能键循环 + 短间隔 |
| P3 | 自动采集 | 重复交互键采集资源 | F 键连按 + 短间隔 |
| P4 | 连点器 | 高速连续点击 | 鼠标/键盘快速连点 |

每套预设可查看详细的操作步骤列表，但不能修改或删除。

### 4.3 自定义方案

用户可以通过 GUI 界面新建自定义操作序列，支持以下操作：

| 操作 | 描述 |
|------|------|
| 添加步骤 | 在序列末尾新增一个操作步骤 |
| 删除步骤 | 删除序列中选中的步骤 |
| 调整顺序 | 上移/下移重新排列步骤顺序 |
| 修改参数 | 点击步骤编辑其具体参数 |

每个步骤可设置的参数：

| 参数 | 说明 | 适用类型 |
|------|------|----------|
| 动作类型 | 键盘按键 / 鼠标点击 / 等待 | 所有 |
| 按键名 | 如 space、f、enter、1-9 等 | 键盘 |
| 鼠标按钮 | 左键 / 右键 | 鼠标 |
| 持续时间 | 按下保持的秒数（默认 0.1） | 键盘、鼠标 |
| 等待时间 | 等待的秒数或随机范围 {min, max} | 等待 |
| 是否循环 | 整体序列无限循环 / 执行一次 | 方案整体 |

### 4.4 方案管理

- **预设方案**：内置于程序代码中，只读，不可删除
- **自定义方案**：存储在程序的本地数据库中
- 预设与自定义方案在同一个列表中展示和切换
- 支持删除自定义方案（预设方案不可删除）

### 4.5 热键系统

- 默认启动热键：**F10**
- 默认停止热键：**F12**
- 热键可自定义（预设和自定义方案各自独立配置）
- 热键为全局热键，游戏在前台全屏运行时也能响应
- 需要管理员权限运行（Windows 全局键盘钩子要求）

界面包含以下区域：

1. **方案列表**：显示所有预设和自定义方案，区分标记（预设/自定义），可选中切换
2. **工具栏**：新建方案、编辑方案（进入步骤编辑器）、删除方案（仅自定义）
3. **状态栏**：当前方案名称、启停热键、运行状态指示灯、运行时长
4. **启停按钮**：界面上的启动/停止按钮
5. **步骤预览**：只读显示当前方案的操作步骤列表
6. **日志区**：带时间戳的运行日志，实时滚动

### 4.8 安全与控制

- 启动时自动请求管理员权限（Windows UAC 提权）
- 可中断的等待：等待期间按下停止键可立即终止
- 明确的运行状态指示（防止重复启动）
- 操作日志带时间戳
- 预设方案只读保护，防止误修改

## 5. 数据存储

| 数据类型 | 存储方式 | 说明 |
|----------|----------|------|
| 预设方案 | 程序代码内定义 | 4 套只读方案，随 EXE 发布 |
| 自定义方案 | SQLite 本地数据库 | 用户新建的方案，持久化保存 |
| 运行日志 | 内存 + 可选导出 | GUI 内实时显示，不自动保存 |

## 6. 非功能需求

| 编号 | 类别 | 要求 |
|------|------|------|
| N1 | 操作系统 | Windows 10 / 11 |
| N2 | 游戏兼容 | 支持全屏 DirectInput 游戏 |
| N3 | 响应延迟 | 停止键按下后 0.2 秒内停止操作 |
| N4 | 资源占用 | 运行时内存占用 < 100MB |
| N5 | 打包 | 单文件 EXE，大小 < 50MB |

## 7. 用户使用流程

### 7.1 使用预设方案

```
1. 双击运行 EXE → 弹出 GUI 窗口（自动请求管理员权限）
2. 在方案列表中浏览并选择一个预设方案
3. 右侧预览区查看该方案的操作步骤
4. 切换到游戏中
5. 按下启动热键（默认 F10）→ 自动操作开始
6. 按下停止热键（默认 F12）→ 操作立即停止
```

### 7.2 创建自定义方案

```
1. 点击 [新建方案] 按钮 → 弹出步骤编辑器
2. 输入方案名称
3. 设置启动/停止热键（或使用默认值）
4. 逐一 [添加步骤]，选择类型并配置参数
5. 通过上移/下移调整步骤顺序
6. 点击 [保存] → 自定义方案出现在列表中
7. 选中该方案即可使用
```

## 8. 范围外（本期不做）

以下功能明确不在本期范围内：

- 屏幕图像识别（找图找色）
- 鼠标移动到指定坐标
- 录制与回放
- 条件分支判断（if/else）
- 定时启动（按时间计划自动运行）
- 多显示器支持
- 方案导入/导出

## 9. 术语表

| 术语 | 说明 |
|------|------|
| 热键 / 快捷键 | 键盘上用于控制启停的按键组合 |
| 操作序列 | 按顺序执行的一组动作（按键/点击/等待） |
| 预设方案 | 内置在程序中的只读操作方案 |
| 自定义方案 | 用户通过 GUI 自行创建的操作方案 |
| 步骤编辑器 | 用于编排操作序列的弹窗界面 |
| DirectInput | Windows 底层输入 API，全屏游戏通常使用此接口接收输入 |
